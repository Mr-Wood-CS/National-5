# Scottish Golfers: INSERT, UPDATE and DELETE

Use the Scotland Golfers database to practise changing records with `INSERT`, `UPDATE` and `DELETE`.

For questions that change the database, a short test query is included. Run the test query after your answer to check whether your SQL has worked.

## Practice

You should practise:

- `INSERT`
- `UPDATE`
- `DELETE`
- referential integrity using primary and foreign keys

---

**Question 1**
A new junior golfer, Eve Muirfoot, has joined Dunfermline Golf Club. After playing a few rounds of golf her handicap is confirmed as 19. She is assigned the golf number 3028756. Add Eve to the database.

To test your answer, run:

```sql
SELECT *
FROM Golfer
WHERE scotGolfNo = 3028756;
```

If your query has been successful, the test query should show one record for Eve Muirfoot.

---

**Question 2**
Eve took part in the adult ladies Arbroath Match match play competition in 2022, scoring 93. Her resultID was OBN0065. Add Eve's result to the database.

To test your answer, run:

```sql
SELECT *
FROM Result
WHERE resultID = 'OBN0065';
```

If your query has been successful, the test query should show one result for Eve Muirfoot's Scottish Golf Number.

**Question 3**
Aki Seng has joined Hawick Golf Club as an adult member. Aki has yet to be given a handicap. Aki has been told his Scottish Golf Number is 4049875. Add Aki to the database.

To test your answer, run:

```sql
SELECT *
FROM Golfer
WHERE scotGolfNo = 4049875;
```

If your query has been successful, the test query should show one record for Aki Seng. The handicap should be blank or `NULL`.

**Question 4**
The database is set up with referential integrity. Explain what would happen if Eve's Arbroath Match competition result from Question 2 was entered into the `Result` table before her details were added to the `Golfer` table in Question 1.

**Question 5**
Having now played enough golf, Aki Seng, scotGolfNo 4049875, has been given a handicap of 26. Scotland Golfers can now add his handicap to the database.

To test your answer, run:

```sql
SELECT scotGolfNo, forename, surname, handicap
FROM Golfer
WHERE scotGolfNo = 4049875;
```

If your query has been successful, the test query should show Aki Seng with a handicap of 26.

**Question 6**
The results of the 2022, Glasgow Seniors, Gents competition have accidentally been entered as a Mixed event. Change these results so that the competition type is Gents.

To test your answer, run:

```sql
SELECT resultID, competition, level, type, year
FROM Result
WHERE competition = 'Glasgow Seniors'
AND level = 'Senior'
AND year = 2022;
```

If your query has been successful, the test query should show the 2022 Senior Glasgow Seniors results with type Gents.
