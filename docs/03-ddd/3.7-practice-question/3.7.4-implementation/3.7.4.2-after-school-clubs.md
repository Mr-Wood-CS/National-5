# After School Clubs

Use this page to practise the SQL skills needed for National 5 Computing Science.

The tasks are based on a small database about school clubs. Some questions ask you to display data, while others ask you to add, update or delete records.

For questions that change the database, a short test query is included. Run the test query after your answer to check whether your SQL has worked.

## ==Select==, ==From== and ==Where== Challenges.

In this section, you will practise writing queries that search the After School Clubs database. Use `SELECT` to choose the fields you want to display, `FROM` to choose the table, and `WHERE` to filter the records so only matching clubs or members are shown. You will also use logical operators such as `AND` and `OR` to combine more than one condition.

Need to revisit the topic? Go back to [SQL SELECT Operations](../../3.4-implementation/3.4.1-sql-select.md).
