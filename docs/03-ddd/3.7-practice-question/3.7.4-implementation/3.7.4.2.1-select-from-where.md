# After School Clubs: SELECT and WHERE

Use the After School Clubs database to practise `SELECT`, `FROM` and `WHERE` queries.

[:material-database: Open the SQL workspace](https://onecompiler.com/sqlite/44t3abhh6){: .inline-launch__link target="_blank" rel="noopener" }

## Practice

You should practise:

- `SELECT ... FROM`
- `WHERE`
- comparison operators such as `=`, `<`, `>`, `<=` and `>=`
- `AND` and `OR`
