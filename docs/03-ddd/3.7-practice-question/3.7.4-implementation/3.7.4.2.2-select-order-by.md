# After School Clubs: SELECT and ORDER BY

Use the After School Clubs database to practise sorting query results with `ORDER BY`.

[:material-database: Open the SQL workspace](https://onecompiler.com/sqlite/44t3abhh6){: .inline-launch__link target="_blank" rel="noopener" }

## Practice

You should practise:

- `SELECT ... FROM`
- `ORDER BY`

---

**Question 1**
Display the members' forenames, surnames and year groups from oldest year group to youngest year group.

---

**Question 2**
Display each club name and category. Display the club names in alphabetical order.

---

**Question 3**
Display each member's forename, surname and clubID. Display the members in surname order.

---

**Question 4**
Display each club name, day and room. Display the clubs in room order.

---

**Question 5**
Display each member's forename, surname and year group. Display the records from youngest year group to oldest year group, then by surname.
