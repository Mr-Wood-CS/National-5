## Challenges

#### 1 - ==Select==, ==From== and ==Where==

In this section, you will practise writing queries that search the Scotland Golfers database. Use `SELECT` to choose the fields you want to display, `FROM` to choose the table, and `WHERE` to filter the records so only matching golfers or results are shown. You will also use logical operators such as `AND` and `OR` to combine more than one condition.

Need to revisit the topic? Go back to [SQL SELECT Operations](../../3.4-implementation/3.4.1-sql-select.md).
