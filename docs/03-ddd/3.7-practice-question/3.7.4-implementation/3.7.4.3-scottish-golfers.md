# Scottish Golfers

Use the Scotland Golfers database to practise SQL skills needed for National 5 Computing Science.

The tasks are split into three sections:

- [SELECT and WHERE](3.7.4.3.1-select-from-where.md)
- [SELECT and ORDER BY](3.7.4.3.2-select-order-by.md)
- [INSERT, UPDATE and DELETE](3.7.4.3.3-insert-update-delete.md)
