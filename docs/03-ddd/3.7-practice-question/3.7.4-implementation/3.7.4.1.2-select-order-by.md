# Videoblogger: SELECT and ORDER BY

Use the Videoblogger database to practise sorting query results with `ORDER BY`.

[:material-database: Open the SQL workspace](https://onecompiler.com/sqlite/44t39rhad){: .inline-launch__link target="_blank" rel="noopener" }

## Practice

You should practise:

- `SELECT ... FROM`
- `WHERE`
- `ORDER BY`

---

**Question 1**
Display all the videos, name and date created, with a rating of 1. Display from oldest to newest.

---

**Question 2**
Display every vlogger's forename, surname and expertise. Display the records in surname order.

---

**Question 3**
Display each video's name and duration. Display the longest videos first.

---

**Question 4**
Display each video's name, date created and rating. Display the newest videos first.

---

**Question 5**
Display every vlogger's username, forename and surname. Display the usernames in alphabetical order.
