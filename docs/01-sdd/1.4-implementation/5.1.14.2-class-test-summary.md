# Task 2: Class Test Summary

In this task, you will create a program that stores pupil names and test scores.

The program will then work out the total and average score.

This task gives you more practice with arrays.

!!! info "The Problem"

    A teacher wants a program that stores the names and scores of three pupils in a class test.

    The program should display each pupil's name and score, then show the total and average.

## Step 3: Design

Design the program before you start coding.

Choose one of these:

- pseudocode
- a structure diagram
- a flowchart

Your design should show this order:

1. get the three names and scores
2. store the names in one array
3. store the scores in another array
4. calculate the total and average
5. display the results

## Step 4: Code

Create the program in Python.

Your program should:

- create an empty array for the pupil names
- create an empty array for the scores
- use `append()` to add each name and score
- convert each score to an integer
- use array indexes when displaying each pupil and score

!!! tip "Small steps"

    Get one pupil name and score working first.

    Then add the second pupil.

    Then add the third pupil.
