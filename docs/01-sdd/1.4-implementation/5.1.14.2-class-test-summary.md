# Task 2: Class Test Summary

A teacher wants a program that stores the names and scores of three pupils in a class test.

The program should ask the user to enter:

- the name of pupil 1
- the score for pupil 1
- the name of pupil 2
- the score for pupil 2
- the name of pupil 3
- the score for pupil 3

The program should store:

- the pupil names in an array
- the test scores in an array

The program should calculate:

- the total score
- the average score

The program should display:

- all three pupil names and scores
- the total score
- the average score
