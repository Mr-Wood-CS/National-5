# Putting It All Together

These tasks bring together the skills you have learned so far in Software Design and Development.

For each task, you should complete the development stages you have learned so far:

1. analyse the problem using an Input-Process-Output table
2. identify the data types and data structures needed
3. design the program using pseudocode
4. create either a structure diagram or a flowchart
5. implement the program in Python

Your Python programs should include:

- internal commentary
- variables
- arrays
- string, integer and real values
- input
- output
- number conversion using `int()` or `float()`
- calculations
- string concatenation or clear use of commas in `print()`
