# Task 1: School Trip Calculator

A teacher wants a program to help calculate the cost of a school trip.

The program should ask the user to enter:

- the pupil's name
- the destination
- the number of pupils going on the trip
- the entry cost per pupil
- the total bus cost

The program should store the destination and pupil name using variables.

The program should store the following labels in an array:

```python
costLabels = ["Entry total", "Bus cost", "Total cost"]
```

The program should calculate:

- the total entry cost
- the total trip cost
- the cost per pupil including the bus cost

The program should display a clear trip summary showing:

- the pupil's name
- the destination
- each cost label from the array
- the total entry cost
- the bus cost
- the total trip cost
- the final cost per pupil
