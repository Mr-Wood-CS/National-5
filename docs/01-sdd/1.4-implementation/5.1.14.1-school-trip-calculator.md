# Task 1: School Trip Calculator

In this task, you will create a program that works out the cost of a school trip.

The program is for a teacher who needs to know:

- how much the trip costs altogether
- how much each pupil needs to pay

Take it one section at a time.

!!! info "The Problem"

    A teacher wants a program to help calculate the cost of a school trip.

    The program will ask for the pupil's name, the trip destination, the number of pupils, the entry cost per pupil, and the bus cost.

## Step 3: Design

Design the program before you start coding.

Choose one of these:

- pseudocode
- a structure diagram
- a flowchart

Your design should show this order:

1. get the information from the user
2. calculate the costs
3. display the trip summary

## Step 4: Code

Create the program in Python.

Use this array in your program:

```python
costLabels = ["Entry total", "Bus cost", "Total cost"]
```

Your program should calculate:

- the total entry cost
- the total trip cost
- the cost per pupil including the bus cost

!!! tip "Remember"

    Use `int()` for whole numbers.

    Use `float()` for numbers that might have decimal places, such as money.
