# If/Else Statements

An `if/else` statement chooses between two paths. One path runs when the condition is true and the other runs when it is false.

## Example

This program checks whether someone is old enough to drive.

```python title="Driving Age Check" linenums="1"
age = int(input("Please enter your age: "))

if age >= 17:
    print("You are old enough to drive")
else:
    print("You are not old enough to drive yet")
```

- When `age >= 17` is true, the first message is displayed.
- Otherwise, the condition is false and the message inside `else` is displayed.

Only one branch can run. The two outcomes are **mutually exclusive**.

## Structure of an If/Else Statement

```python
if condition:
    statement_when_true
else:
    statement_when_false
```

Both `if` and `else` end with a colon. The statements belonging to each branch must be indented.

!!! note

    `else` does not have its own condition. It means "when the `if` condition is false".

## Another Example

```python title="Even or Odd"
number = int(input("Enter a whole number: "))

if number % 2 == 0:
    print("The number is even")
else:
    print("The number is odd")
```
