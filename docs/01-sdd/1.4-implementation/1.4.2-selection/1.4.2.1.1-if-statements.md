# If Statements

An `if` statement runs a block of code only when its condition is true.

## Designing an If Statement

This pseudocode describes a password check with one possible action:

```pseudocode title="Password Check Design" linenums="1"
1 password = input
2 IF password = "hello123" THEN
3     SEND "Access granted" TO DISPLAY
4 END IF
```

If the condition is false, the program skips the indented instruction and continues after `END IF`.

## Implementing an If Statement

This program grants access only when the user enters the correct password.

```python title="Password Check" linenums="1"
password = input("Please enter the password: ")

if password == "hello123":
    print("Access granted")
```

The Python condition is `password == "hello123"`. Notice that the pseudocode uses `=` for comparison, while Python uses `==`.

- If the condition is true, `Access granted` is displayed.
- If the condition is false, the indented line is skipped.

## Structure of an If Statement

```python
if condition:
    statement
```

An `if` statement:

1. Starts with the keyword `if`.
2. Contains a condition.
3. Ends with a colon (`:`).
4. Uses indentation to show which statements belong to it.

Several statements can be placed inside the same `if` block, provided they have the same indentation.

```python title="Checking a Score"
if score >= 10:
    print("Target reached")
    print("Well done!")
```

## Common Mistakes

!!! failure "Incorrect"

    ```python
    if password = "hello123"
    print("Access granted")
    ```

This example uses one equals sign, has no colon, and does not indent the statement.

!!! success "Correct"

    ```python
    if password == "hello123":
        print("Access granted")
    ```
