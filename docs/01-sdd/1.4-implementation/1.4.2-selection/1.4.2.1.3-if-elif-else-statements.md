# If/Elif/Else Statements

Use `if/elif/else` when a program must choose between more than two paths. `elif` is short for **else if**.

## Designing Several Paths

A program can use several branches to assign a grade from a percentage mark.



```pseudocode title="Assigning a Grade Design" linenums="1"
1 mark = integer input

2 IF mark >= 70 THEN

3     grade = "A"

4 ELSE IF mark >= 60 THEN

5     grade = "B"

6 ELSE IF mark >= 50 THEN

7     grade = "C"

8 ELSE

9     grade = "F"

10 END IF

11 SEND grade TO DISPLAY
```

## Implementing Several Paths

```python title="Assigning a Grade" linenums="1"
mark = int(input("Please enter the percentage mark: "))

if mark >= 70:
    grade = "A"
elif mark >= 60:
    grade = "B"
elif mark >= 50:
    grade = "C"
else:
    grade = "F"

print(grade)
```

Python checks the conditions from top to bottom:

1. If `mark >= 70` is true, the grade is `A`.
2. Otherwise, if `mark >= 60` is true, the grade is `B`.
3. Otherwise, if `mark >= 50` is true, the grade is `C`.
4. If every condition is false, the `else` branch assigns `F`.

As soon as a true condition is found, its branch runs and the remaining branches are skipped. Only one branch runs.

## Order Matters

Conditions should usually be arranged from the highest value to the lowest value.

If `mark >= 50` appeared first, a mark of `75` would satisfy it and incorrectly receive a `C`. Python would never reach the check for an `A`.

## Structure of an If/Elif/Else Statement

```python
if first_condition:
    first_statement
elif second_condition:
    second_statement
else:
    fallback_statement
```

You can use more than one `elif` branch. The final `else` provides an outcome when none of the conditions are true. It is optional, but including it ensures that the selection always has a fallback outcome.
