## Complex Conditions

A complex condition combines or changes conditions using the logical operators `and`, `or` and `not`.

For example, a percentage is valid when it is greater than or equal to 0 **and** less than or equal to 100.

```python title="Checking a Percentage" linenums="1"
if percentage >= 0 and percentage <= 100:
    print("Valid percentage")
```

- `53` passes both comparisons, so the whole condition is true.
- `110` passes the first comparison but fails the second, so the whole condition is false.
- `-273` fails the first comparison, so the whole condition is false.

---

## And

Use `and` when both conditions must be true.

```python title="Checking an Age Range" linenums="1"
if age >= 17 and age <= 100:
    print("You are between 17 and 100")
```

The message is displayed only when the age passes both comparisons.

---

## Or

Use `or` when at least one condition must be true. The condition is also true when both conditions are true.

```python title="Checking the Weather" linenums="1"
if weather == "rain" or weather == "cloudy":
    print("It is not nice weather today")
```

The message is displayed when the weather is `"rain"` or `"cloudy"`.

---

## Not

Use `not` to reverse a condition. A true condition becomes false, and a false condition becomes true.

```python title="Reversing a Condition" linenums="1"
if not age < 17:
    print("You are not less than 17")
    print("You must be at least 17")
```

In this example, `not age < 17` has the same effect as `age >= 17`.

---

## Writing Conditions in Full

Each part of a complex condition must contain a complete comparison.

!!! failure "Incorrect"

    ```python
    if weather == "rain" or "cloudy":
        print("It is not nice weather today")
    ```

!!! success "Correct"

    ```python
    if weather == "rain" or weather == "cloudy":
        print("It is not nice weather today")
    ```

The incorrect version does not compare `weather` with `"cloudy"`.

---

## Summary

| Operator | Purpose | The whole condition is true when... |
|----------|---------|-------------------------------------|
| `and` | Combines required conditions | Both conditions are true |
| `or` | Combines alternative conditions | At least one condition is true |
| `not` | Reverses a condition | The original condition is false |
