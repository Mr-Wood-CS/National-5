## Task 1: Youth Club

A youth club can only accept people who are 21 years old or younger.

Write a program that:

1. asks the user to enter their age as a whole number
2. checks whether the age is greater than 21
3. displays `Too old` only when the age is greater than 21

If the age is 21 or younger, the program should not display a message.

### Design

Use the [structure diagram guidance](1.4.2.1-simple-conditional-statements.md#selection-in-structure-diagrams), then [open draw.io](https://app.diagrams.net/) and create a **structure diagram**. Your diagram must include:

- an input task for the person's age
- a selection question that asks whether the age is greater than 21
- a **Yes** outcome with a subtask that displays `Too old`

The **No** outcome does not need a subtask because the program does nothing when the condition is false.

Add the completed structure diagram to your workbook.

### Implement

Create a Python program that matches your structure diagram. Use an `if` statement.

### Add to Your Workbook

Add a screenshot of your Python code to your workbook. Run the program twice and include output showing:

- an age greater than 21
- an age of 21 or younger, showing that the warning is not displayed

## Task 2: Machine Temperature

A machine must be stopped when its temperature falls to 6°C or below.

Write a program that:

1. asks the operator to enter the machine temperature as a whole number
2. checks whether the temperature is less than or equal to 6
3. displays `Stop the machine` when the condition is true
4. displays `Temperature is safe` when the condition is false

### Design

Use the [flowchart guidance](1.4.2.1-simple-conditional-statements.md#selection-in-flowcharts), then [open draw.io](https://app.diagrams.net/) and create a **flowchart**. Your flowchart must include:

- a start symbol
- an input symbol for the temperature
- a decision symbol that checks whether the temperature is less than or equal to 6
- a **Yes** path that displays `Stop the machine`
- a **No** path that displays `Temperature is safe`
- an end symbol

Label both paths leaving the decision and add the completed flowchart to your workbook.

### Implement

Create a Python program that matches your flowchart. Use an `if/else` statement.

### Add to Your Workbook

Add a screenshot of your Python code to your workbook. Run the program twice and include output showing:

- a temperature of 6 or below
- a temperature greater than 6

## Task 3: Museum Guide

A museum has three exhibitions. The user selects an exhibition by entering its number.

| Number entered | Output |
|---|---|
| `1` | `Ancient Egypt is on the ground floor` |
| `2` | `Space Exploration is on the first floor` |
| `3` | `Scottish Wildlife is on the second floor` |
| Any other number | `Invalid exhibition number` |

Write a program that:

1. displays the three exhibition numbers and names
2. asks the user to enter an exhibition number
3. displays the matching location, or the error message if the number is not valid

### Design

Review the [pseudocode guidance](1.4.2.1-simple-conditional-statements.md#selection-in-pseudocode-and-python), then write **pseudocode** for the program in your workbook. Include:

- the exhibition menu and user input
- a separate simple condition for each valid number
- every possible output
- an `ELSE` for an invalid number
- `END IF`

Each condition should contain only one comparison.

### Implement

Create a Python program that matches your pseudocode. Use `if`, `elif`, and `else`.

### Add to Your Workbook

Add a screenshot of your Python code to your workbook. Run the program four times and include output showing selections `1`, `2`, `3`, and an invalid number.
