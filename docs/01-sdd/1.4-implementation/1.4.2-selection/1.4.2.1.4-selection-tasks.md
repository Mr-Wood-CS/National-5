## Task 2: Youth Club

A program asks for a person's age when they try to join a youth club. People who are over 21 should be told that they are `Too old`.

> a. In your workbook, complete the condition by replacing the placeholder with the correct comparison operator.
    ```text
    age [comparison operator] 21
    ```

> b. Write the pseudocode for the program in your workbook. Remember to include the input.

> c. Implement your design in Python and test that the program works.

## Task 3: Machine Temperature

A factory program asks the operator to enter a machine's temperature. If the temperature is 6 or less, it should display a warning telling the operator to stop the machine.

> a. In your workbook, complete the condition by choosing a suitable variable name, comparison operator and value.
    ```text
    [variable] [comparison operator] [value]
    ```
> b. Write pseudocode for the program in your workbook. Remember to include the input.

> c. Implement your design in Python and test that the program works.

## Task 4: Clothing Advice

Write a program that suggests what clothing to wear based on the temperature:

- Below 0°C: suggest a heavy coat, gloves and a hat.
- From 0°C to below 10°C: suggest a jacket and sweater.
- From 10°C to 20°C: suggest a light jacket or sweater.
- Above 20°C: suggest short sleeves and light clothing.

> a. In your workbook, complete the value comparisons by replacing each placeholder with the correct comparison operator.
    ```text
    temperature [comparison operator] 0
    temperature [comparison operator] 10
    temperature [comparison operator] 20
    ```

> b. Create the flowchart in draw.io and add a screenshot to your workbook.

> c. Implement your design in Python using `if`, `elif` and `else`. Test that each possible branch works.
