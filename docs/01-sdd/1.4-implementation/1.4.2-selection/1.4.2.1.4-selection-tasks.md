## Task 1: Youth Club

A youth club asks for a person's age. If the person is over 21, the program should display `Too old`.

### Design

Use the [structure diagram guidance](1.4.2.1-simple-conditional-statements.md#selection-in-structure-diagrams), then [open draw.io](https://app.diagrams.net/) and create a **structure diagram**. Include:

- an input task for the person's age
- a selection that checks whether the age is over 21
- the required output

Add the completed structure diagram to your workbook.

### Implement

Create a Python program that matches your structure diagram.

### Add to Your Workbook

Add screenshots of your Python code and program output to your workbook.

## Task 2: Machine Temperature

A factory program asks the operator to enter a machine's temperature. If the temperature is 6°C or less, the program should display `Stop the machine`.

### Design

Use the [flowchart guidance](1.4.2.1-simple-conditional-statements.md#selection-in-flowcharts), then [open draw.io](https://app.diagrams.net/) and create a **flowchart**. Use the correct symbols for:

- entering the temperature
- checking the temperature
- displaying the warning

Label both paths leaving the decision and add the completed flowchart to your workbook.

### Implement

Create a Python program that matches your flowchart.

### Add to Your Workbook

Add screenshots of your Python code and program output to your workbook.

## Task 3: Clothing Advice

A program asks the user to enter the temperature and displays suitable clothing advice.

| Temperature | Output |
|---|---|
| Below 0°C | `Wear a heavy coat, gloves and a hat` |
| From 0°C to below 10°C | `Wear a jacket and sweater` |
| From 10°C to 20°C inclusive | `Wear a light jacket or sweater` |
| Above 20°C | `Wear short sleeves and light clothing` |

### Design

Review the [pseudocode guidance](1.4.2.1-simple-conditional-statements.md#selection-in-pseudocode-and-python), then write **pseudocode** for the program in your workbook. Include:

- the temperature input
- every condition and possible output
- `END IF`

### Implement

Create a Python program that matches your pseudocode. Use `if`, `elif`, and `else`.

### Add to Your Workbook

Add screenshots of your Python code and program output to your workbook.
