# Task 3: Bake Sale Takings

In this task, you will create a program that works out how much money was made at a bake sale.

This task uses arrays and calculations together.

!!! info "The Problem"

    A charity group wants a program to calculate the money made from cupcakes, brownies and cookies.

    The program should also subtract the ingredient cost to work out the profit.

## Step 3: Design

Design the program before you start coding.

Choose one of these:

- pseudocode
- a structure diagram
- a flowchart

Your design should show this order:

1. set up the item names and prices
2. ask how many of each item was sold
3. ask for the ingredient cost
4. calculate the money made
5. calculate the profit
6. display the summary

## Step 4: Code

Create the program in Python.

Use these arrays in your program:

```python
itemNames = ["Cupcakes", "Brownies", "Cookies"]
itemPrices = [1.50, 2.00, 0.75]
```

Your program should calculate:

- the money made from cupcakes
- the money made from brownies
- the money made from cookies
- the total money made
- the profit

!!! tip "Remember"

    Use the item prices from the array when doing your calculations.

    Use `float()` for the ingredient cost because it might include pence.
