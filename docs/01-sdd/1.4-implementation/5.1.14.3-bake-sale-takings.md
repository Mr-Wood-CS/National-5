# Task 3: Bake Sale Takings

A charity group wants a program to calculate how much money was made at a bake sale.

The program should use these arrays:

```python
itemNames = ["Cupcakes", "Brownies", "Cookies"]
itemPrices = [1.50, 2.00, 0.75]
```

The program should ask the user to enter:

- how many cupcakes were sold
- how many brownies were sold
- how many cookies were sold
- the cost of ingredients

The program should calculate:

- the money made from cupcakes
- the money made from brownies
- the money made from cookies
- the total money made
- the profit

The program should display a clear bake sale summary showing:

- each item name from the array
- the money made from each item
- the total money made
- the ingredient cost
- the profit
