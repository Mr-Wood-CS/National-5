# Scottish Golfers Answers

These are suggested SQL answers for the Scottish Golfers OneCompiler challenges.

## SELECT, FROM and WHERE Challenge

**Question 1**

Output the scores of every golfer who played in the Edinburgh Masters competition.

```sql
SELECT score
FROM Result
WHERE competition = 'Edinburgh Masters';
```

---

**Question 2**

Output the full names of all the senior members of Dundee Golf Club.

```sql
SELECT forename, surname
FROM Golfer
WHERE age = 'Senior'
AND club = 'Dundee Golf Club';
```

---

**Question 3**

Output the full names and club of all junior golfers with a handicap less than 10.

```sql
SELECT forename, surname, club
FROM Golfer
WHERE age = 'Junior'
AND handicap < 10;
```

---

**Question 4**

Output the resultID and score from all the match play competitions in 2021.

```sql
SELECT resultID, score
FROM Result
WHERE matchType = 'match play'
AND year = 2021;
```

---

**Question 5**

Output the full name, ScotGolfNo and score of all the Dumfries Golf Club members who have played in a 2021 competition.

```sql
SELECT Golfer.forename, Golfer.surname, Golfer.scotGolfNo, Result.score
FROM Golfer, Result
WHERE Golfer.scotGolfNo = Result.scotGolfNo
AND Golfer.club = 'Dumfries Golf Club'
AND Result.year = 2021;
```

---

**Question 6**

Output the full names of all the senior golfers who scored less than 72 in 2021.

```sql
SELECT Golfer.forename, Golfer.surname
FROM Golfer, Result
WHERE Golfer.scotGolfNo = Result.scotGolfNo
AND Golfer.age = 'Senior'
AND Result.score < 72
AND Result.year = 2021;
```

---

**Question 7**

Output the full name of all the junior golfers who played in a 2021 or 2022 senior competition.

```sql
SELECT Golfer.forename, Golfer.surname
FROM Golfer, Result
WHERE Golfer.scotGolfNo = Result.scotGolfNo
AND Golfer.age = 'Junior'
AND Result.level = 'Senior'
AND (Result.year = 2021 OR Result.year = 2022);
```

---

**Question 8**

Output a list of all the junior golfers, including the Scottish Golf Number, with a handicap greater than 10 who played in mixed competition and scored less than 80.

```sql
SELECT Golfer.scotGolfNo, Golfer.forename, Golfer.surname
FROM Golfer, Result
WHERE Golfer.scotGolfNo = Result.scotGolfNo
AND Golfer.age = 'Junior'
AND Golfer.handicap > 10
AND Result.type = 'Mixed'
AND Result.score < 80;
```

## ORDER BY Challenge

**Question 1**

Output each golfer's Scottish Golf Number, forename and surname. Display the records in Scottish Golf Number order.

```sql
SELECT scotGolfNo, forename, surname
FROM Golfer
ORDER BY scotGolfNo ASC;
```

---

**Question 2**

Output the club and handicap of all golfers with the surname White. Display the records in club order.

```sql
SELECT club, handicap
FROM Golfer
WHERE surname = 'White'
ORDER BY club ASC;
```

---

**Question 3**

Output the resultID, year and score for the senior ladies results from the Dunfermline Open. Display the records in resultID order.

```sql
SELECT resultID, year, score
FROM Result
WHERE competition = 'Dunfermline Open'
AND level = 'Senior'
AND type = 'Ladies'
ORDER BY resultID ASC;
```

---

**Question 4**

Output the resultID, competition and score for all results with a score greater than 95. Display the highest scores first.

```sql
SELECT resultID, competition, score
FROM Result
WHERE score > 95
ORDER BY score DESC;
```

---

**Question 5**

Output the forename, surname and handicap of junior golfers with a handicap between 14 and 21. Display the highest handicaps first.

```sql
SELECT forename, surname, handicap
FROM Golfer
WHERE age = 'Junior'
AND handicap >= 14
AND handicap <= 21
ORDER BY handicap DESC;
```

---

**Question 6**

Output the resultID, competition and score for senior competitions in 2022. Display the lowest scores first.

```sql
SELECT resultID, competition, score
FROM Result
WHERE level = 'Senior'
AND year = 2022
ORDER BY score ASC;
```

---

**Question 7**

Output the resultID, competition, matchType and score for stroke play results in 2021. Display the records in score order, then resultID order.

```sql
SELECT resultID, competition, matchType, score
FROM Result
WHERE matchType = 'stroke play'
AND year = 2021
ORDER BY score ASC, resultID ASC;
```

This sorts the records by `score` first. If two or more records have the same score, those matching-score records are then sorted by `resultID`.

---

**Question 8**

Output the resultID, year and score for the 2022, Ladies, Sanquhar Open competition. Display the highest scores first, then display matching scores in resultID order.

```sql
SELECT resultID, year, score
FROM Result
WHERE competition = 'Sanquhar Open'
AND year = 2022
AND type = 'Ladies'
ORDER BY score DESC, resultID ASC;
```

## INSERT, UPDATE and DELETE Challenge

**Question 1**

A new junior golfer, Eve Muirfoot, has joined Dunfermline Golf Club. After playing a few rounds of golf her handicap is confirmed as 19. She is assigned the golf number 3028756. Add Eve to the database.

```sql
(scotGolfNo, forename, surname, age, club, handicap)
VALUES
(3028756, 'Eve', 'Muirfoot', 'Junior', 'Dunfermline Golf Club', 19);
```

Having now played enough golf, Aki Seng, scotGolfNo 4049875, has been given a handicap of 26. Scotland Golfers can now add his handicap to the database.

## Equi-Joins Challenge

**Question 1**

Output the forename, surname, age and score of golfers who scored more than 95. Display the highest scores first.

```sql
SELECT Golfer.forename, Golfer.surname, Golfer.age, Result.score
FROM Golfer, Result
WHERE Golfer.scotGolfNo = Result.scotGolfNo
AND Result.score > 95
ORDER BY Result.score DESC;
```

---

**Question 2**

Output the forename, surname and score for golfers who played in a senior competition in 2022. Display the records in surname order.

```sql
SELECT Golfer.forename, Golfer.surname, Result.score
FROM Golfer, Result
WHERE Golfer.scotGolfNo = Result.scotGolfNo
AND Result.level = 'Senior'
AND Result.year = 2022
ORDER BY Golfer.surname ASC;
```
