# Scottish Golfers: Equi-Joins

Use the Scotland Golfers database to practise simple equi-joins using primary and foreign keys.

[:material-database: Open the SQL workspace](https://onecompiler.com/sqlite/44wp4ncrc){: .inline-launch__link target="_blank" rel="noopener" }

## Practice

You should practise:

- `SELECT ... FROM`
- `WHERE`
- `ORDER BY`
- simple equi-joins using primary and foreign keys

---

**Question 1**
Output the forename, surname, age and score of golfers who scored more than 95. Display the highest scores first.

---

**Question 2**
Output the forename, surname and score for golfers who played in a senior competition in 2022. Display the records in surname order.
