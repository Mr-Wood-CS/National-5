# After School Clubs Answers

These are suggested SQL answers for the After School Clubs OneCompiler challenges.

## SELECT, FROM and WHERE Challenge

**Question 1**

```sql
SELECT *
FROM Member;
```

---

**Question 2**

```sql
SELECT forename, surname, yearGroup
FROM Member;
```

---

**Question 3**

```sql
SELECT *
FROM Club
WHERE category = 'Computing';
```

---

**Question 4**

```sql
SELECT forename, surname
FROM Member
WHERE yearGroup = 3;
```

---

**Question 5**

```sql
SELECT clubName, room
FROM Club
WHERE category = 'Computing'
AND day = 'Friday';
```

---

**Question 6**

```sql
SELECT forename, surname, yearGroup
FROM Member
WHERE yearGroup = 3
OR yearGroup = 5;
```

## INSERT, UPDATE and DELETE Challenge

```sql
INSERT INTO Club

(8, 'Netball Club', 'Sport', 'Wednesday', 'Gym');
```

---

**Question 2**

```sql
UPDATE Club
SET room = 'Gym'
WHERE clubName = 'Football Club';
```

## Equi-Joins Challenge

**Question 1**

```sql
SELECT Member.forename, Member.surname, Club.clubName, Club.day
FROM Member, Club
WHERE Member.clubID = Club.clubID;
```

---

**Question 2**

```sql
SELECT Member.forename, Member.surname
FROM Member, Club
WHERE Member.clubID = Club.clubID
AND Club.category = 'Sport'
ORDER BY Member.surname ASC;
```

---

**Question 3**

```sql
SELECT Member.forename, Member.surname, Member.yearGroup, Club.category
FROM Member, Club
WHERE Member.clubID = Club.clubID;
```

---

**Question 4**

```sql
SELECT Member.forename, Member.surname
FROM Member, Club
WHERE Member.clubID = Club.clubID
AND Club.category = 'Computing';
```

---

**Question 5**

```sql
SELECT Club.clubName, Member.forename, Member.surname
FROM Member, Club
WHERE Member.clubID = Club.clubID
ORDER BY Club.clubName ASC;
```
